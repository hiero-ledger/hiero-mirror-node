# CLPR proto field access paths

How each persisted CLPR field is obtained: from the submitted `TransactionBody`, the classic
`TransactionRecord`, or a block-stream `StateChange` (map update/delete or singleton update) surfaced via
`StateChangeContext`. "Set by" lists the transaction type(s) that populate the field.

## Channel (`clpr_channel` / `clpr_channel_history`)

| Field                                                                                                                                                                                              | Access path                                                                                                                                                                                      | Set by                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| `channel_id`                                                                                                                                                                                       | TransactionBody (`ClprCompleteChannel.channel_id`)                                                                                                                                               | `ClprCompleteChannel`                                         |
| `created_timestamp`                                                                                                                                                                                | Derived (consensus timestamp of the transaction)                                                                                                                                                 | `ClprCompleteChannel`                                         |
| `chain_id`                                                                                                                                                                                         | StateChange map update, `STATE_ID_CLPR_CHANNELS` (`ClprChannel.chain_id`)                                                                                                                        | `ClprCompleteChannel`                                         |
| `verifier_contract_id`                                                                                                                                                                             | TransactionBody (`ClprCompleteChannel.verifier_contract`)                                                                                                                                        | `ClprCompleteChannel`                                         |
| `verifier_fingerprint`                                                                                                                                                                             | StateChange map update, `STATE_ID_CLPR_CHANNELS` (`ClprChannel.verifier_fingerprint`)                                                                                                            | `ClprCompleteChannel`                                         |
| `status`                                                                                                                                                                                           | StateChange map update, `STATE_ID_CLPR_CHANNELS` (`ClprChannel.status`)                                                                                                                          | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |
| `next_message_id`                                                                                                                                                                                  | StateChange map update, `STATE_ID_CLPR_CHANNELS`                                                                                                                                                 | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |
| `acked_message_id`                                                                                                                                                                                 | StateChange map update, `STATE_ID_CLPR_CHANNELS`                                                                                                                                                 | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |

| `received_running_hash`                                                                                                                                                                            | StateChange map update, `STATE_ID_CLPR_CHANNELS`                                                                                                                                                 | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |
| `ownership_commitment`                                                                                                                                                                             | StateChange map update, `STATE_ID_CLPR_CHANNELS`; also independently recomputed as `keccak256(channel_id, public_key)` from TransactionBody for the paired `clpr_channel_pending_commitment` row | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |
| `trust_anchor`                                                                                                                                                                                     | StateChange map update, `STATE_ID_CLPR_CHANNELS`                                                                                                                                                 | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |
| `trust_anchor_id`                                                                                                                                                                                  | StateChange map update, `STATE_ID_CLPR_CHANNELS`                                                                                                                                                 | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |
| `channel_context`                                                                                                                                                                                  | StateChange map update, `STATE_ID_CLPR_CHANNELS`                                                                                                                                                 | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |
| `endpoint_manifest_version`                                                                                                                                                                        | StateChange map update, `STATE_ID_CLPR_CHANNELS`                                                                                                                                                 | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |
| `last_config_timestamp`                                                                                                                                                                            | StateChange map update, `STATE_ID_CLPR_CHANNELS` (`ClprChannel.last_config_timestamp`, optional)                                                                                                 | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |
| `peer_config_timestamp`                                                                                                                                                                            | StateChange map update, `STATE_ID_CLPR_CHANNELS` (`ClprChannel.peer_config_timestamp`, optional)                                                                                                 | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |

| `endpoint_manifest` (jsonb)                                                                                                                                                                        | StateChange map update, `STATE_ID_CLPR_CHANNELS` (`ClprChannel.endpoint_manifest.endpoints`, optional)                                                                                           | `ClprCompleteChannel`, `ClprSubmitBundle`, `ClprCloseChannel` |

Note: all `StateChange`-sourced fields above are read indirectly — the block-stream transformer
(`ClprCompleteChannelTransformer` / `ClprSubmitBundleTransformer` / `ClprCloseChannelTransformer`) looks up
`StateChangeContext.getClprChannel(channel_id)` and stashes the resulting `ClprChannel` proto on
`RecordItem.clprChannel`; the transaction handler then reads `recordItem.getClprChannel()` rather than touching
`StateChangeContext` directly. `channel_id` for that lookup comes from the TransactionBody of the respective
transaction (`ClprCompleteChannel.channel_id`, `ClprSubmitBundle.channel_id`, `ClprCloseChannel.channel_id`).

| `signature`                     | TransactionBody (`ClprCompleteChannel.signature`)                                                                                                                       | `ClprCompleteChannel`                                                                                               |

## Ledger configuration (`clpr_ledger_configuration`, singleton)

| Field                                                                                                                                                           | Access path                                                                                                                                                                                           | Set by                          |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| `consensus_timestamp`                                                                                                                                           | Derived (consensus timestamp)                                                                                                                                                                         | `ClprUpdateLedgerConfiguration` |
| `protocol_version`                                                                                                                                              | StateChange singleton update, `STATE_ID_CLPR_LEDGER_CONFIGURATION` (`ClprLedgerConfiguration.protocol_version`) — **not** read from the submitted body, which isn't trustworthy past the first update | `ClprUpdateLedgerConfiguration` |
| `chain_id`                                                                                                                                                      | StateChange singleton update, `STATE_ID_CLPR_LEDGER_CONFIGURATION`                                                                                                                                    | `ClprUpdateLedgerConfiguration` |
| `service_address`                                                                                                                                               | StateChange singleton update, `STATE_ID_CLPR_LEDGER_CONFIGURATION`                                                                                                                                    | `ClprUpdateLedgerConfiguration` |
| `initial_trust_anchor`                                                                                                                                          | StateChange singleton update, `STATE_ID_CLPR_LEDGER_CONFIGURATION`                                                                                                                                    | `ClprUpdateLedgerConfiguration` |
| `initial_trust_anchor_id`                                                                                                                                       | StateChange singleton update, `STATE_ID_CLPR_LEDGER_CONFIGURATION`                                                                                                                                    | `ClprUpdateLedgerConfiguration` |
| `max_gas_per_message`, `max_local_endpoints`, `max_message_payload_bytes`, `max_messages_per_bundle`, `max_peer_endpoints`, `max_queue_depth`, `max_sync_bytes` | StateChange singleton update, `STATE_ID_CLPR_LEDGER_CONFIGURATION` (`ClprLedgerConfiguration.throttles.*`, optional)                                                                                  | `ClprUpdateLedgerConfiguration` |

Access path detail: `ClprUpdateLedgerConfigurationTransformer` reads
`StateChangeContext.getClprLedgerConfiguration()` and stashes it on `RecordItem.clprLedgerConfiguration`; the
handler reads `recordItem.getClprLedgerConfiguration()`. This mirrors the Channel pattern above.

Same configuration shape (`protocol_version`, `chain_id`, `service_address`, `initial_trust_anchor`,
`initial_trust_anchor_id`, throttle fields) is also mapped into `clpr_message.control_configuration` (jsonb) when
a `ClprSubmitBundle` dispatches a CONTROL message carrying a config update — see Message table below. In that
case the source is the `ClprMessageValue.payload.control.config_update.configuration` embedded in the
dispatched message itself (via `StateChangeContext`'s message-queue map update), not the ledger-configuration
singleton.

## Endpoint manifest (`clpr_endpoint_manifest`, singleton)

Not populated by design, not a gap: per `docs/design/clpr.md` (Architecture point 5 and Consensus-Node
Assumption #4), there is currently no transaction or `StateChange` for the mirror node to anchor this to — the
per-round reconciler that produces `clpr_endpoint_manifest_value` has no block-stream artifact today. Schema,
domain model, repository, and `EntityListener.onClprEndpointManifest(...)` are wired ahead of time so ingestion
can be added once consensus-node emits the expected synthetic system transaction for this.

## Message (`clpr_message`, partitioned, append-only)

All fields below are sourced from the dispatched `clpr_message_key`/`clpr_message_value` map-update entries off
`StateChangeContext` (`STATE_ID_CLPR_MESSAGE_QUEUE`). `ClprSubmitBundleTransformer` collects these via
`StateChangeContext.getClprMessages()` and stashes them on `RecordItem.clprMessages` (in dispatch order); the
handler expands each entry into a row. Set only by `ClprSubmitBundle`.

| Field                           | Access path                                                                                                                 | Notes                                                  |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| `channel_id`                    | StateChange map update, `STATE_ID_CLPR_MESSAGE_QUEUE` (`ClprMessageKey.channel_id`)                                         |                                                        |
| `message_id`                    | StateChange map update, `STATE_ID_CLPR_MESSAGE_QUEUE` (`ClprMessageKey.message_id`)                                         |                                                        |
| `consensus_timestamp`           | Derived (consensus timestamp)                                                                                               |                                                        |
| `running_hash`                  | StateChange map update (`ClprMessageValue.running_hash_after_processing`)                                                   |                                                        |
| `message_type`                  | StateChange map update (`ClprMessageValue.payload` oneof case: `MESSAGE`→DATA, `MESSAGE_REPLY`→RESPONSE, `CONTROL`→CONTROL) |                                                        |
| `connector_id`                  | StateChange map update (`ClprMessageValue.payload.message.connector_id`)                                                    | DATA messages only                                     |
| `sender`                        | StateChange map update (`ClprMessageValue.payload.message.sender`)                                                          | DATA messages only                                     |
| `target_application`            | StateChange map update (`ClprMessageValue.payload.message.target_application`)                                              | DATA messages only                                     |
| `message_data`                  | StateChange map update (`ClprMessageValue.payload.message.message_data` or `...message_reply.message_reply_data`)           | DATA and RESPONSE messages                             |
| `reply_to_message_id`           | StateChange map update (`ClprMessageValue.payload.message_reply.message_id`)                                                | RESPONSE messages only                                 |
| `reply_status`                  | StateChange map update (`ClprMessageValue.payload.message_reply.status`)                                                    | RESPONSE messages only                                 |
| `control_configuration` (jsonb) | StateChange map update (`ClprMessageValue.payload.control.config_update.configuration`, optional)                           | CONTROL messages only, when a config update is present |
